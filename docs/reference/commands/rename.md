# knapper rename

```text
Rename a note and update all links to it

Usage: knapper rename [OPTIONS] <OLD> <NEW>

Arguments:
  <OLD>  
  <NEW>  

Options:
  -c, --config <CONFIG>  Path to config file
      --dry-run          
  -f, --format <FORMAT>  [default: text]
  -v, --vault <VAULT>    Path to vault (overrides config)
  -h, --help             Print help
```
