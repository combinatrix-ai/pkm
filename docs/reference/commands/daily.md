# knapper daily

```text
Create or get daily note

Usage: knapper daily [OPTIONS] [DATE]

Arguments:
  [DATE]  

Options:
  -c, --config <CONFIG>  Path to config file
  -p, --path-only        
  -f, --format <FORMAT>  [default: text]
  -v, --vault <VAULT>    Path to vault (overrides config)
  -h, --help             Print help
```
