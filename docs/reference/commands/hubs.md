# pkm hubs

```text
Find hub notes (most linked-to notes)

Usage: pkm hubs [OPTIONS]

Options:
  -c, --config <CONFIG>  Path to config file
  -l, --limit <LIMIT>    [default: 10]
  -f, --format <FORMAT>  [default: text]
  -v, --vault <VAULT>    Path to vault (overrides config)
  -h, --help             Print help
```
