# pkm v0.1.0

The first release of pkm: a headless CLI for Markdown and Org knowledge bases, built for people and AI agents working from the terminal. It reads and edits the notes in place, with no note-taking app, daemon, server or index.

## Highlights

- **Query the vault.** Filter and sort notes by frontmatter, inline fields, tags and link counts with `query`; list the fields in use with `fields`.
- **Follow the link graph.** Backlinks, outgoing links, orphans, hubs, and broken links down to headings and block IDs, for both `[[wikilinks]]` and `[markdown](links.md)`.
- **Refactor without breaking links.** `rename` and `move` rewrite every link to the note, for a single note or a whole directory, and preview the change with `--dry-run`. `repair-links --dry-run` proposes fixes where the files give unambiguous evidence.
- **Tags as topics.** `backlinks '#tag'` and `context '#tag'` follow nested tags; `demote` turns wikilinks used as labels into tags.
- **Tasks.** Create, filter and update checkboxes across the vault, with dates, priorities, configurable statuses and recurring tasks in the Tasks plugin format. Status changes select a task by its full text, which `tasks --format json` returns, and several tasks in one file can change in one checked write.
- **Notes from templates and daily notes,** including Core Templates and supported Templater date expressions.
- **Vault health.** Lint frontmatter and required headings by path or metadata, across the vault or only the files Git reports as changed.
- **Context for agents.** `context` returns a note's content and relationships in one JSON object. The agent skill is embedded in the binary and registered with Claude Code and Codex on install.
- **External references.** Keep `pkm://` references in notes and resolve them through provider commands you configure, such as a password manager CLI.
- **Names in any script.** Tags are Unicode-aware, links match case-insensitively beyond ASCII, and a file name stored decomposed (as macOS can) matches a link typed composed.

## Install and update

```sh
curl -fsSL https://raw.githubusercontent.com/combinatrix-ai/pkm/v0.1.0/install.sh | sh
```

Archives are available for macOS arm64/x86_64 and Linux arm64/x86_64 (musl); Windows is not a release target. Each archive and the checksum manifest carry GitHub Actions provenance attestations. The installer verifies checksums, places the binary in `~/.local/bin`, and registers the agent skill; use `--skill none` to skip that.

Release binaries update themselves: `pkm self-update` verifies the next release's provenance before installing it. Interactive commands check for a new release in the background at most every six hours and only print a notice; set `PKM_NO_UPDATE_CHECK=1` to turn the check off. A copy installed with `cargo install` is left to cargo, and the notice names the command to run.

This is the first release, so updating from one release to the next has not yet been exercised; the next release will be the first to check it.
